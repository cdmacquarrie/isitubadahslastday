Add a new round

Paste the full HTML of a round's results page (view-source, or the saved .html from the inspector bookmarklet). Round number and name are detected automatically when possible.

Paste song length data

This dashboard runs in a sandbox that blocks outside network requests, so it can't look up song lengths itself. Run the separate Song Length Fetcher file in a normal browser tab, then paste its output here.

Publish to the site

Anything imported above lives only in this browser. To make it public, download the regenerated data file and drop it into music/ in the repo — it replaces the whole page, so the committed SEED_DATA stays in sync with what you see here.
