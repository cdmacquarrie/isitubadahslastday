🎧 Music League — Live Dashboard

Standings, charts and superlatives across every season so far.

Add a new round

Paste the full HTML of a round's results page (view-source, or the saved .html from the inspector bookmarklet). Round number and name are detected automatically when possible.

Paste song length data

This dashboard runs in a sandbox that blocks outside network requests, so it can't look up song lengths itself. Run the separate Song Length Fetcher file in a normal browser tab, then paste its output here.

Publish to the site

Anything imported above lives only in this browser. To publish it, download the data files and drop them into ML/data/ in the repo — pushing them rebuilds this page automatically. Song lengths only change when you import new ones, so that file is usually not worth re-downloading.

Genre tags are approximate classifications, not official Music League data. Charts are generated in your browser from the season data published with this page. · istodayubadahslastday.art
